# Dog-ear 產品規格（開發用）

> 本文件整合 PRD、Day 1 資訊架構、Day 2–3 線框稿與視覺討論的所有決策。與 Figma 不一致時，以本文件為準，並提出來確認。

## 1. 產品概述

- **一句話定位**：把紙本題本的多益閱讀錯題，變成會自己排程複習的個人題庫。
- **使用者**：用紙本題本準備多益的考生，弱項是閱讀（Part 5、6、7）。
- **核心循環**：拍照錄入錯題 → 標記錯因 → 系統排定複習日 → 到期時重做 → 依結果重新排程，直到「已掌握」。
- **核心主張**：複習是「重做」，不是「重看」。

### 範圍

| 版本 | 內容 |
| --- | --- |
| MVP（本次開發） | 拍照錄入、錯因標記、間隔複習、錯題庫、每日上限、錯因管理、ZIP 備份、首次使用引導 |
| P1（有餘裕再做） | 錯因統計圖、照片裁切 |
| v2（之後） | Tesseract.js 離線 OCR、文字搜尋、複習時打亂選項 |

**不做**：聽力（Part 1–4）、帳號與雲端同步、內建題庫、任何後端或 AI 呼叫。

## 2. 資訊架構

- **錄入流程**與**今日複習流程**為全螢幕，隱藏導覽列；結束後回到進入前的頁面。
- 首次開啟引導只出現一次。

## 3. 功能規格

### 3.1 複習頁（首頁）

- 頁首：標題「複習」，右上角齒輪 → 設定。
- 主卡片（右上角有折角）：今天要複習的題數、預估時間（每題約 20 秒，無條件進位到分鐘）、順延題數（超過每日上限的部分），以及「開始複習」按鈕。
- 數據列三格：連續天數、錯題總數、本週新增。
- 提示列（Banner），同時最多顯示一條，優先序：
  1. 不是從主畫面開啟 → 「加入主畫面，避免錯題資料被系統清除 →」，點擊前往 `/welcome`
  2. 有錯題且超過 7 天未備份（或從未備份）→ 「已經 N 天沒有備份，點這裡匯出 →」，點擊直接匯出
- 狀態：
  - **有待複習**：如上。
  - **還沒有錯題**：紙狗 Logo、標題「還沒有錯題」、說明「先錄入你寫錯的題目，系統會從隔天開始幫你安排複習。」、按鈕「新增第一題」。
  - **今天沒有到期**：卡片標題「今天沒有要複習的題目」、說明「明天有 N 題，記得回來。」（N 為 0 時改顯示下一個有題目的日期）；如果今天有新增錯題，再加一行「今天新增的錯題會從明天開始複習。」；按鈕「去新增錯題」。
  - **今日已複習完**：與「今天沒有到期」相同版面，說明改為「今天的複習完成了！明天有 N 題。」

**連續天數**：從今天（若今天已完成至少一題複習）或昨天往回數，連續「有至少一筆 ReviewLog」的天數。今天還沒複習時不中斷昨天以前的連續紀錄。

### 3.2 錄入流程（`/capture`，全螢幕）

頁首：左側 ✕（關閉）、標題「新增錯題」、右側「第 N 題」（本次連續錄入的序號）。

**表單欄位（依此順序）**

| 欄位 | 元件 | 必填 | 說明 |
| --- | --- | --- | --- |
| 照片 | 縮圖列＋「＋ 照片」 | 是，至少 1 張 | 可拍照或從相簿選，可多張（Part 7 常需文章頁＋題目頁） |
| Part | 三個並排大按鈕 5／6／7 | 是 | 單選 |
| 我的答案 | A／B／C／D／未作答 | 是 | 單選 |
| 正確答案 | A／B／C／D | 是 | 單選 |
| 錯因 | 膠囊標籤，可多選 | 是，至少 1 個 | 見下方規則 |
| 題本來源、頁碼／題號、筆記 | 預設折疊的「選填：題本來源、頁碼、筆記 ⌄」 | 否 | 題本來源預設帶入上次填的值 |

- **照片處理**：選取後立即壓縮，長邊 1600px、JPEG 品質約 0.8，存為 Blob。
- **錯因標籤**：
  - 依使用次數由多到少排序，最多顯示 8 個；其餘收進「更多錯因 ⌄」，點擊展開。
  - 最後一個是虛線標籤「＋ 新增錯因」：彈出輸入框，名稱不可與現有錯因（含封存）重複，建立後自動勾選。錄入時只能新增，不能改名、封存或合併。
- **猜對的題目**：當「我的答案」與「正確答案」相同時，在答案區下方顯示提示「猜對的題目也可以收錄，一樣要選一個錯因。」，不阻擋存檔。
- **存檔按鈕**：固定在畫面底部（不隨表單捲動）。必填欄位未完成時停用，並在按鈕上方以小字標示缺少的第一項（例如「還沒選正確答案」）。
- **中途離開**：已有照片或任何欄位已填但未存檔時，按 ✕ 要確認「要捨棄這題嗎？」。

**存檔後**：底部彈出面板（Sheet），背景為半透明遮罩：

- 小字「已存檔第 N 題」、標題「接下來？」
- 「再拍一題」（主要按鈕，預設）：清空表單，**保留 Part 與題本來源**，回到照片步驟。
- 「沿用這組照片，再新增一題」：保留照片、Part、題本來源，清空答案、錯因、頁碼與筆記（Part 6、7 一組照片對應多題時使用）。
- 「完成」：進入「這次寫了幾題」。

**這次寫了幾題**（Sheet）：

- 標題「這次練習寫了幾題？」
- 說明「本次錄入 N 題：答錯 X 題、猜對 Y 題」（Y 為 0 時省略「、猜對 Y 題」）
- 數字輸入框（`inputmode="numeric"`），輸入後即時顯示「這次答錯率約 Z%」，Z = X ÷ 輸入值，四捨五入到整數。輸入值必須 ≥ X（本次錄入題數不含猜對），否則提示「寫的題數不能少於答錯的題數」。
- 「完成」：寫入一筆 PracticeSession，回到進入錄入前的頁面。
- 「略過」：同樣寫入 PracticeSession，但 `attempted` 留空（不列入答錯率統計）。

### 3.3 今日複習流程（`/review`，全螢幕）

**出題清單**：在開始時決定並固定，中途不變。

- 條件：`status === 'learning'` 且 `nextReviewDate <= 今天`。
- 排序：逾期最久（`nextReviewDate` 最早）→ 等級最低 → 建立時間最早。
- 取前 `dailyLimit` 題（預設 20），其餘順延，不受懲罰。

**單題畫面**

頁首：✕、進度「3 / 12」、右側以該 Part 顏色顯示「Part 5」；頁首下方有進度條。

1. **作答**：題目照片（可點擊全螢幕、雙指縮放；多張照片可左右滑動）、「選出你的答案」、A／B／C／D 四個按鈕、下方「不會」按鈕。
2. **揭曉：答錯**（含選「不會」）：卡片（右上角折角）標題「答錯了！下次再努力」、「你的答案 B ・ 正解 D」（選不會時顯示「你選了不會 ・ 正解 D」）、原本的錯因標籤＋「＋ 追加錯因」、筆記（可點擊編輯）、主要按鈕「下一題」。
3. **揭曉：答對**：卡片標題「答對了！正解 C」、說明「這題你是有把握，還是猜的？」，兩個並排按鈕：左「猜的／憑印象」（次要樣式）、右「有把握」（主要樣式），下方小字「選「猜的」這題不會升級，會照原本的間隔再出現」。選擇後直接進入下一題。
4. **完成**：紙狗 Logo、「今日複習完成」、「明天有 N 題」，四格數據：完成題數、答對率（有把握 ÷ 完成題數）、連續天數、新增已掌握題數，按鈕「完成」回到複習頁。

- 每題作答結果**立即**寫入資料庫（Question 更新＋一筆 ReviewLog）。中途按 ✕ 離開後，已作答的題目保留結果；再次進入時，只出還沒作答的到期題目。
- 按 ✕ 時若尚有未作答題目，確認「要先離開嗎？已作答的題目會保留進度。」

### 3.4 錯題庫（`/library`）

- 頁首標題「錯題庫」（無齒輪）。
- 篩選標籤列：Part ⌄、錯因 ⌄、狀態 ⌄（全部／學習中／已掌握，預設「學習中」）。篩選條件以底部面板選擇，可多選 Part 與錯因。
- 「共 N 題」與排序切換「依新增日期 ⇅」／「依下次複習 ⇅」。
- 列表項：左側 4px 的 Part 色書籤條、縮圖（第一張照片）、標題「Part 5・單字、文法」（猜對的題目加「猜對・」前綴）、副標「下次複習：明天・等級 2」或「已掌握」，右側 ›。
- 日期顯示：今天→「今天」、明天→「明天」，其餘「11/3」。
- 篩選無結果：「沒有符合的題目」＋「清除篩選」按鈕。

**單題詳情**（`/library/:id`）

- 頁首：‹ 返回、標題「錯題詳情」、右側「編輯」（進入與錄入相同的表單，存檔後回到詳情）。
- 照片（可放大）、「Part 5 ・ 題本來源 頁碼」、「你的答案 B ・ 正解 D」、錯因標籤、筆記、「複習進度：等級 2・下次複習 11/3」。
- 作答紀錄：日期＋結果，例如「10/28　答錯（選 B）」「10/29　答對・有把握」「10/31　答對・猜的」「11/2　不會」。
- 按鈕：「加入今日複習」（把 `nextReviewDate` 設為今天；已掌握的題目同時改回學習中，等級不變）、「重設進度」（確認後：等級 0、學習中、下次複習明天）、文字按鈕「刪除這題」（確認後刪除題目與其 ReviewLog）。

### 3.5 設定（`/settings`）

列表項：

- 每日複習上限：數字，範圍 5–100，預設 20。
- 錯因管理 → `/settings/tags`，右側顯示「N 個使用中」。
- 匯出備份：右側顯示「上次 10/23」或「尚未備份」。
- 匯入備份：副標「會覆蓋目前所有資料」。
- 關於 Dog-ear：版本號。

### 3.6 錯因管理（`/settings/tags`）

- 頁首右側「＋ 新增」。
- 「使用中（拖曳排序）」清單：拖曳把手、名稱、使用題數、⋯ 選單。
- 「已封存」清單：名稱、「N 題保留原本的標記」、右側「取消封存」。
- 底部說明「已使用的錯因只能封存或合併，未使用的才能刪除。」

| 操作 | 條件 | 行為 |
| --- | --- | --- |
| 新增 | 隨時 | 名稱不可重複（含封存的錯因） |
| 改名 | 隨時 | 直接儲存，題目資料不必變動 |
| 排序 | 拖曳 | 決定手動排序；錄入畫面仍以使用次數排序，次數相同時用手動排序 |
| 刪除 | 只限使用題數為 0 | 確認後刪除 |
| 封存 | 使用題數 > 0 | 說明「舊題目會保留這個標記，但錄入時不會再出現」後確認 |
| 合併 | 使用題數 > 0 | 選擇目標錯因 → 確認「將有 N 題改標為 X」→ 所有題目改標（已同時有兩者的題目去重），原錯因刪除 |
| 取消封存 | 已封存 | 回到使用中 |

至少要保留一個使用中的錯因，否則封存／刪除／合併最後一個時要阻擋並提示。

### 3.7 備份與還原

- **匯出**：產生 `dog-ear-backup-YYYYMMDD.zip`，內含 `data.json`（所有資料表，照片欄位改存檔名）與 `images/` 資料夾（照片原檔）。優先使用 Web Share API 分享檔案（iOS 可存到「檔案」或雲端硬碟），不支援時改為下載。成功後更新 `lastBackupAt`。
- **匯入**：選擇 ZIP → 解析並顯示摘要「備份日期 10/23・錯題 48 題」→ 二次確認「匯入會覆蓋目前所有資料，確定嗎？」→ 清空所有資料表後寫入 → 完成提示。檔案格式錯誤時提示「這不是 Dog-ear 的備份檔」。
- `data.json` 帶 `schemaVersion: 1`，供未來升級使用。

### 3.8 首次開啟與資料保護

- 判斷是否從主畫面啟動：`window.matchMedia('(display-mode: standalone)').matches || navigator.standalone === true`。
- 第一次開啟且不是從主畫面啟動 → 進入 `/welcome`：紙狗 Logo、標題「把 Dog-ear 加入主畫面」、說明「iPhone 會清除太久沒開啟的網站資料。加入主畫面後，你的錯題會保存得更安全。」、三個步驟（1 點 Safari 下方的分享按鈕／2 選擇「加入主畫面」／3 之後從主畫面的 Dog-ear 圖示開啟）、示意圖、按鈕「我知道了」、文字按鈕「先略過」。兩者都記錄「已看過引導」並回到複習頁。
- 從主畫面啟動時，呼叫一次 `navigator.storage.persist()`。
- 不是從主畫面啟動時，複習頁持續顯示加入主畫面的提示列（見 3.1）。

### 3.9 空狀態與邊界情況

| 情境 | 處理 |
| --- | --- |
| 照片無法讀取或壓縮失敗 | 「這張照片無法讀取，請重新拍攝或選擇」 |
| 儲存空間不足（寫入失敗） | 「手機空間不足，請先匯出備份」 |

## 4. 間隔複習演算法

固定間隔（Leitner），等級 0–5：

```ts
export const INTERVALS = [1, 2, 4, 7, 15, 30] as const; // 天，索引 = 等級

type Result = 'sure' | 'guessed' | 'wrong'; // 「不會」視為 wrong

function schedule(q: { level: number }, result: Result, today: string) {
  if (result === 'wrong') return { level: 0, status: 'learning', next: addDays(today, 1) };
  if (result === 'guessed') return { level: q.level, status: 'learning', next: addDays(today, INTERVALS[q.level]) };
  // sure
  if (q.level >= 5) return { level: 5, status: 'mastered', next: null };
  const level = q.level + 1;
  return { level, status: 'learning', next: addDays(today, INTERVALS[level]) };
}
```

- 新增錯題：等級 0，`nextReviewDate = 明天`（錄入當天不出題）。
- 一題最快約 59 天、連續 6 次「有把握」後成為已掌握（第 1、3、7、14、29、59 天複習）。
- 已掌握的題目不再排程；可在單題詳情「加入今日複習」。
- 所有日期為本地日期 `YYYY-MM-DD`，午夜換日；`addDays` 以本地日曆計算（注意夏令時間不影響台灣，但仍不要用毫秒相加後轉 UTC）。

**必測案例**：新題排程、每個等級答對／猜的／答錯、等級 5 答對變已掌握、逾期題目答對時從「今天」起算、每日上限排序、跨月與跨年的日期加法、本地日期在早上 8 點前不會被算成前一天。

## 5. 資料結構（Dexie）

```ts
type Choice = 'A' | 'B' | 'C' | 'D';

interface Question {
  id: string;                  // crypto.randomUUID()
  part: 5 | 6 | 7;
  images: Blob[];              // 壓縮後的照片
  myAnswer: Choice | 'blank';  // blank = 未作答
  correctAnswer: Choice;
  errorTagIds: string[];       // 至少一個
  source?: string;             // 題本名稱
  pageRef?: string;            // 頁碼／題號
  note?: string;
  sessionId?: string;          // 所屬 PracticeSession
  level: 0 | 1 | 2 | 3 | 4 | 5;
  status: 'learning' | 'mastered';
  nextReviewDate: string | null; // YYYY-MM-DD；已掌握為 null
  createdAt: string;           // ISO 時間
  updatedAt: string;
  ocrText?: string;            // v2 預留
}
// 衍生：myAnswer === correctAnswer 即為「猜對」的題目

interface ErrorTag {
  id: string;
  name: string;
  order: number;               // 手動排序
  archived: boolean;
  isDefault: boolean;
}

interface ReviewLog {
  id: string;
  questionId: string;
  reviewedAt: string;          // ISO 時間
  reviewDate: string;          // YYYY-MM-DD，計算連續天數用
  answer: Choice | 'unknown';  // unknown = 不會
  result: 'sure' | 'guessed' | 'wrong';
  levelBefore: number;
  levelAfter: number;
}

interface PracticeSession {    // 一次連續錄入 = 一筆
  id: string;
  date: string;                // YYYY-MM-DD
  attempted?: number;          // 這次寫了幾題；略過則為空
  wrongCount: number;          // 答錯題數（不含猜對）
  guessedCount: number;
  source?: string;
}

interface Settings {           // 單筆，id 固定為 'app'
  id: 'app';
  dailyLimit: number;          // 預設 20
  lastSource?: string;
  lastBackupAt?: string;
  onboardingSeen: boolean;
}
```
