# Dog-ear 開發排程（Day 4–10）

每天一個範圍。開工時把當天的區塊貼給 Claude Code，例如：「依 `docs/BUILD_PLAN.md` 的 Day 5 實作，完成後列出驗收結果。」

每天收工前：
- `npm run build`、`npm run test` 通過
- 在手機（或 390px 寬度）實際操作一遍
- 寫 3–5 行開發日誌到 `docs/DEVLOG.md`：做了什麼決策、為什麼、卡在哪裡（作品集素材）

---

## Day 4：專案骨架

**任務**
1. 用 Vite 建立 React + TypeScript 專案，安裝技術棧（見 `CLAUDE.md`）。
2. 在 `src/index.css` 設定 tokens 與 Google Fonts（見 `DESIGN.md`）。
3. `src/lib/date.ts`：`today()`、`addDays()`、`diffDays()`、`formatShort()`（今天／明天／11/3），全部使用本地日期，附單元測試。
4. `src/db/schema.ts`：Dexie 資料表與索引；首次啟動建立 8 個預設錯因與 Settings。
5. React Router 路由與底部導覽列；各頁先放標題佔位。
6. PWA 設定：manifest（名稱 Dog-ear、`display: standalone`、`theme_color` 與 `background_color` 為 #F7FAFF、zh-TW）、紙狗圖示、離線快取。
7. 部署到 Vercel。

**驗收**
- 手機開啟部署網址 → 加入主畫面 → 從主畫面開啟為全螢幕 App，三個分頁可切換。
- `date.ts` 測試通過，包含早上 8 點前的本地日期案例。

## Day 5：錄入流程

**任務**
1. 元件：Button、Option、Chip、Photo、Header/Flow、Sheet。
2. `src/lib/image.ts`：照片壓縮（長邊 1600px）。
3. `/capture` 表單：照片、Part、我的答案（含未作答）、正確答案、錯因（使用次數排序、最多 8 個、更多錯因、＋ 新增錯因）、選填欄位折疊。
4. 存檔按鈕固定底部、缺少欄位提示、中途離開確認、猜對提示。
5. 存檔後面板（再拍一題／沿用這組照片／完成）與「這次寫了幾題」面板，寫入 PracticeSession。

**驗收**
- 用真實題本錄入至少 5 題，單題錄入時間在 30 秒內。
- 「沿用這組照片」能為同一篇 Part 7 文章連續新增多題。
- 重新整理頁面後資料仍在。

## Day 6：複習排程與今日複習

**任務**
1. `src/lib/scheduler.ts`：依 `PRD.md` 第 4 節實作，附完整單元測試（必測案例全部要有）。
2. 出題清單：篩選、排序、每日上限。
3. `/review`：作答（含不會）、答錯、答對（有把握／猜的）、完成畫面；每題立即寫入 Question 與 ReviewLog；中途離開與繼續。
4. 複習頁（首頁）：主卡片、數據列、四種狀態、連續天數計算、FoldCorner 元件。

**驗收**
- 開發用：在設定加一個「僅開發環境」可見的按鈕，把所有題目的 `nextReviewDate` 設為今天，用來測試（正式版不顯示）。
- 複習 Day 5 錄入的題目，跑通完整的核心循環。
- 單元測試全部通過。

## Day 7：錯題庫

**任務**
1. `/library`：列表、Part 書籤條、縮圖、篩選（Part／錯因／狀態）、排序、空結果。
2. `/library/:id`：詳情、作答紀錄、編輯（重用錄入表單）、加入今日複習、重設進度、刪除。
3. 照片全螢幕檢視與縮放（複習頁也共用）。

**驗收**
- 能依錯因篩出「單字」的所有題目。
- 編輯錯題後回到詳情，資料正確。
- 刪除題目後，其 ReviewLog 一併刪除。

## Day 8：設定、錯因管理、備份、資料保護

**任務**
1. `/settings`：每日上限、錯因管理入口、匯出、匯入、關於。
2. `/settings/tags`：新增、改名、拖曳排序、刪除、封存、合併、取消封存，以及「至少保留一個」的限制。
3. `src/lib/backup.ts`：ZIP 匯出（Web Share API 優先）與匯入（摘要、二次確認、覆蓋）。
4. `src/lib/standalone.ts`：主畫面偵測、`navigator.storage.persist()`、`/welcome` 首次開啟引導、複習頁提示列（主畫面與備份提醒）。

**驗收**
- 合併「搭配詞」到「單字」後，相關題目改標正確，且不重複。
- 匯出 ZIP → 清除網站資料 → 匯入 → 題目、照片、作答紀錄完整還原。
- iPhone Safari 第一次開啟會看到加入主畫面引導。

## Day 9：實際使用與修正

**任務**
1. 用自己的真實錯題完整使用一天：錄入一批、隔天複習。
2. iPhone Safari 實測：鍵盤彈出時存檔按鈕位置、安全區、照片縮放手勢、面板捲動、相機權限。
3. 處理邊界情況（`PRD.md` 3.9）與發現的問題。

**驗收**
- 把遇到的問題與修正記錄在 `docs/DEVLOG.md`。

## Day 10：打磨與上線

**任務**
1. 視覺對齊 Figma「高保真 v1」：間距、字級、折角、狀態樣式。
2. 細節：按鈕按下回饋、頁面切換、載入狀態、`prefers-reduced-motion`。
3. 正式部署，在手機上做最後一次完整流程。
4. 整理作品集素材：各畫面截圖、核心流程錄影、`DEVLOG.md` 精華。

**驗收**
- 從加入主畫面、錄入、複習到備份，完整走過一次沒有阻礙。
